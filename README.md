# HulkBC GitHub Pages support site

This repository supports ownership verification and any published GitHub Pages content. Do not delete verification files, deployed site content or required Pages artifacts without approval.

## Standing weekly GitHub storage and cost governance

The founder-approved, read-only, cross-project audit is performed by ChatGPT on Monday mornings and covers this repository and all other HulkBC repositories. It reviews GitHub Actions artifacts, GitHub Packages, releases, caches, retention, and runner costs; reports evidence-backed cleanup/archive candidates; and requests explicit founder approval for **each** proposed deletion, archive, retention or workflow change. No site content, verification tokens or critical rollback evidence should be removed without validating dependencies. See the [permanent cross-project policy](https://github.com/HulkBC/ai-development-os/blob/main/docs/GITHUB_STORAGE_COST_GOVERNANCE.md). This audit is separate from GitHub Pages deployment.
